# Security policy

## Supported versions

Only the latest release gets fixes. Update before reporting.

## How to report a vulnerability

Please do **not** open a public issue. Use [private vulnerability reporting](https://github.com/JulianR87/TURBiX/security/advisories/new) (Security tab, then “Report a vulnerability”). Include the TURBiX and Windows versions, the steps to reproduce it and what an attacker could do with it.

## What to expect

TURBiX is kept by volunteers. You will get a reply within a few days, a fix as soon as it can be made and credit in the release notes if you want it. There are no bounties.

## Scope

The code in this repository: how TURBiX uses administrator rights, the backups and restores, the installer and uninstaller, and the files it writes. Antivirus false positives are not vulnerabilities: use the “False positive” form in Issues.
