# Sicherheitsrichtlinie

## Unterstützte Versionen

Nur die neueste Version erhält Korrekturen. Aktualisiere, bevor du etwas meldest.

## So meldest du eine Sicherheitslücke

Bitte eröffne **kein** öffentliches Issue. Nutze die [private Meldung von Sicherheitslücken](https://github.com/JulianR87/TURBiX/security/advisories/new) (Reiter Security, dann „Report a vulnerability“). Gib die Versionen von TURBiX und Windows an, die Schritte zum Nachstellen und was jemand damit anstellen könnte.

## Was dich erwartet

TURBiX wird von Freiwilligen gepflegt. Du bekommst innerhalb weniger Tage eine Antwort, eine Korrektur, sobald sie fertig ist, und auf Wunsch eine Nennung in den Versionshinweisen. Prämien gibt es nicht.

## Geltungsbereich

Der Code in diesem Repository: wie TURBiX Administratorrechte nutzt, die Sicherungen und Wiederherstellungen, Installer und Deinstallation sowie die Dateien, die es schreibt. Fehlalarme von Virenscannern sind keine Sicherheitslücken: nutze dafür das Formular „Fehlalarm“ in den Issues.
