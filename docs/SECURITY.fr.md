# Politique de sécurité

## Versions prises en charge

Seule la dernière version reçoit des correctifs. Mettez à jour avant de signaler.

## Comment signaler une vulnérabilité

Merci de **ne pas** ouvrir d’issue publique. Utilisez le [signalement privé de vulnérabilités](https://github.com/JulianR87/TURBiX/security/advisories/new) (onglet Security, puis « Report a vulnerability »). Indiquez les versions de TURBiX et de Windows, les étapes pour reproduire le problème et ce qu’une personne malveillante pourrait en faire.

## À quoi s’attendre

TURBiX est maintenu par des bénévoles. Vous recevrez une réponse en quelques jours, un correctif dès que possible et une mention dans les notes de version si vous le souhaitez. Il n’y a pas de primes.

## Périmètre

Le code de ce dépôt : la façon dont TURBiX utilise les droits d’administrateur, les sauvegardes et restaurations, l’installeur et le désinstalleur, et les fichiers qu’il écrit. Les faux positifs d’antivirus ne sont pas des vulnérabilités : utilisez le formulaire « Faux positif » dans Issues.
