# Как помочь проекту TURBiX

Спасибо, что хотите помочь. TURBiX — открытый бесплатный проект, который развивается в свободное время, и любая помощь важна. Уметь программировать не обязательно.

## Чем можно помочь

- **Сообщить об ошибке.** Создайте [issue](https://github.com/JulianR87/TURBiX/issues/new/choose) и укажите версию Windows и TURBiX, что вы сделали и чего ожидали. Очень помогает журнал действий (страница **Журнал действий**, кнопка *Копировать*).
- **Предложить улучшение** в разделе [Issues](https://github.com/JulianR87/TURBiX/issues) или задать любой вопрос в [Discussions](https://github.com/JulianR87/TURBiX/discussions).
- **Улучшить перевод.** Тексты лежат в обычных текстовых файлах в `src/Turbix/Strings`. Руководство: [`tools/TRANSLATING.ru.md`](../tools/TRANSLATING.ru.md).
- **Прислать код** через pull request. Начать удобно с issue с меткой `good first issue`.
- **Сообщить о ложном срабатывании антивируса.** Напишите, какой антивирус и как называется обнаружение, чтобы мы сообщили производителю.

## Сборка

Нужен [.NET SDK](https://dotnet.microsoft.com/download) (6 или новее). Запустите `build.cmd`; получатся `dist\TURBiX.exe` и `dist\TURBiX-Setup.exe`.

## Правила для кода

1. **Программа должна работать на любом ПК с чистой Windows 10 (1607+) или 11.** Никаких загрузок, дополнительных пакетов, PowerShell внутри программы и обращений к Интернету.
2. **Всё можно отменить.** Настройка сначала сохраняет исходное значение и отменяется в разделе **Восстановление**.
3. **Безопасность не трогаем.** Ничего, что отключает Центр обновления Windows, Microsoft Defender, SmartScreen или брандмауэр, и никаких «трюков», которые что-то ломают.
4. **Никакого текста прямо в коде.** Весь видимый текст находится в `Strings`, на всех шести языках. `python tools/check_strings.py` должен вывести `OK`.
5. **У каждого параметра есть кнопка «?»** с коротким и честным объяснением. Без обещаний, которые программа не может выполнить.
6. **Проверяйте перед отправкой.** Всё, что меняет Windows, тестируйте в виртуальной машине и напишите в pull request, что именно вы проверили.

Один pull request — одно изменение. Issue и pull request можно писать на английском или испанском.

## Проблемы безопасности

Не создавайте публичный issue об уязвимости. Используйте **Security › Report a vulnerability** на странице репозитория, чтобы её можно было исправить до публикации.
