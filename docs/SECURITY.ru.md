# Политика безопасности

## Поддерживаемые версии

Исправления выходят только для последней версии. Обновитесь, прежде чем сообщать.

## Как сообщить об уязвимости

Пожалуйста, **не** создавайте публичный issue. Используйте [закрытое сообщение об уязвимостях](https://github.com/JulianR87/TURBiX/security/advisories/new) (вкладка Security, затем «Report a vulnerability»). Укажите версии TURBiX и Windows, шаги для воспроизведения и что можно сделать с помощью этой уязвимости.

## Чего ожидать

TURBiX поддерживают добровольцы. Ответ придёт в течение нескольких дней, исправление выйдет, как только будет готово, а по желанию вас назовут в заметках к версии. Вознаграждений нет.

## Что входит

Код этого репозитория: как TURBiX использует права администратора, резервные копии и восстановление, установщик и удаление, а также файлы, которые он записывает. Ложные срабатывания антивирусов уязвимостями не считаются: для них есть форма «Ложное срабатывание» в Issues.
