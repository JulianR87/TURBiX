What it does

Privacy and telemetry

Stops Windows sending data to Microsoft. Every setting explains what it does and what you give up, and the ones that can switch off a feature are marked as advanced.

  • Diagnostic data level, the DiagTrack service and 10 data-collection tasks
  • Advertising ID, activity history, and ads and suggestions in Start and Explorer
  • Copilot and Recall, plus telemetry in Office, NVIDIA, Edge and developer tools

Cleanup

Scans first and shows how much space each category takes. You decide what goes.

  • Temporary files, update downloads, error reports, memory dumps and logs
  • Cache of Chrome, Edge, Brave, Firefox, Discord, Teams, Spotify and Steam
  • Cookies, passwords and history are never touched

Performance

Control what starts with Windows, see what is running and free RAM when it is nearly full.

  • Startup programs on or off, the same way Task Manager does it
  • Processes grouped under the program that opened them
  • Automatic memory cleanup from the icon next to the clock
  • 13 gaming settings, each with a real and documented effect

Fixes

Finds out why the PC is slow and runs the standard Windows repairs.

  • PC checkup: drive type, free space, memory, startup load, pending restart
  • SFC, DISM, disk check, network reset and stuck print queue
  • Registry cleanup that only flags entries it can prove are broken
  • If the cause is an old hard drive or too little RAM, it says so

Also included: removal of preinstalled apps, a hardware health report, an activity log and a What's new page. Six languages, light and dark theme.

What it won't touch

Optimizers earn a bad name by breaking things. TURBiX leaves out the tweaks that do.

  • Windows Update, Microsoft Defender, SmartScreen and the firewall
  • The hosts file
  • Browser cookies, passwords, history and open sessions
  • Xbox services, SysMain on SSDs, the page file and bcdedit
  • Files in use: their cache is skipped

How undo works

  1. TURBiX saves the original value of everything it is about to change.
  2. It applies your selection and writes every step to a daily activity log.
  3. In Restore you pick a session and put it back. It can also create a Windows restore point first.

Files deleted in Cleanup and removed Windows apps can't be restored from there. The app warns you before you confirm.

Questions

Will it make my PC faster?

It depends on what is slowing it down. Fewer startup programs, more free space and fewer unused services make a visible difference. If the cause is a mechanical drive or too little memory, TURBiX tells you, only a hardware change fixes that.

Can I undo what it did?

Yes, from Restore, one whole session at a time. Two things can't be undone there: files deleted in Cleanup and removed Windows apps, which you reinstall from Microsoft Store.

Does it send any data?

No. It has no network code. The one exception is announced on screen: the DISM repair can make Windows itself download files from Windows Update.

Why does it need administrator rights?

Services, scheduled tasks and system settings can't be changed without them.

Is cleaning the registry safe?

TURBiX only removes entries that point to files it has verified are missing, and saves a copy first. It never “optimizes” the registry, and it says plainly that cleaning it won't make the PC faster.

Does it have to stay open?

No. Settings stay applied after you close it. Keep it next to the clock only if you want automatic memory cleanup.

How do I update?

Install the new version over the old one, your settings and backups stay. With the portable file, replace it.
