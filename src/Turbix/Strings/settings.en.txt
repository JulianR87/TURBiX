settings.language.text = Unless you pick another one, TURBiX uses your Windows language.
settings.language.help = TURBiX is available in Spanish, English, Portuguese (Brazil), French, German and Russian. “Same as Windows” uses your Windows display language; if it isn't one of these, TURBiX shows in English.\n\nThe change shows up the next time TURBiX opens, and it doesn't touch anything in Windows.

settings.section.background = Startup and background
settings.tray.title = Show the icon next to the clock
settings.tray.text = Double-click opens TURBiX; right-click gives you shortcuts to free up memory, clean temporary files or exit.
settings.tray.help = While TURBiX is open, its icon sits in the notification area, next to the clock on the taskbar. If you can't see it, it may be tucked under the “Show hidden icons” arrow; you can drag it from there onto the taskbar.\n\nDouble-click opens the window. Right-click to free up RAM, clean temporary files, open Settings or exit TURBiX.\n\nIf you turn this off, the icon only appears briefly when TURBiX shows you a notification.
settings.tray.log.on = The TURBiX icon is shown next to the clock.
settings.tray.log.off = The TURBiX icon is no longer shown next to the clock.
settings.closeToTray.title = Keep running when the window is closed
settings.closeToTray.text = The X hides the window and TURBiX stays next to the clock. To close it completely, use “Exit TURBiX” in the icon's menu.
settings.closeToTray.needsIcon = This needs the icon next to the clock: without it there'd be no way back to the window, so the X closes TURBiX.
settings.closeToTray.help = With this on, closing the window with the X doesn't close TURBiX: it keeps running next to the clock and the automatic memory cleanup carries on. To get back, double-click the icon or open TURBiX again.\n\nTo close it completely, right-click the icon and choose “Exit TURBiX”.\n\nWith it off, the X closes TURBiX like any other program.\n\nWith the window hidden, TURBiX barely uses the processor: it just checks memory every 30 seconds.
settings.confirmExit.title = Ask before exiting
settings.confirmExit.text = Asks you to confirm before closing TURBiX, so you don't close it by accident.
settings.confirmExit.help = Shows a prompt before TURBiX closes completely, whether from “Exit TURBiX” in the icon's menu or with the X if you set it to close.\n\nIf a task is running, TURBiX never closes halfway through: it waits for it to finish, whether this option is on or not.

settings.section.data = TURBiX data
settings.data.title = Data folder
settings.data.open = Open folder
settings.data.help = This is where TURBiX keeps the backup of every change (the ones “Restore” uses) and the activity log for each day. Only administrators can change it.\n\nDon't delete the backups if you want to be able to undo the changes you applied.
settings.reset.title = Reset settings
settings.reset.text = Puts the options on this page back to how they came. Backups and the changes TURBiX made to Windows aren't touched.
settings.reset.button = Reset
settings.reset.help = Goes back to the defaults: theme and language same as Windows, not opening at sign-in, no automatic memory cleanup, icon next to the clock, and asking before exiting.\n\nIt doesn't undo anything TURBiX changed in Windows: that's what “Restore” is for.
settings.reset.confirm.title = Reset TURBiX settings?
