net.help.traffic = Every program that uses the network, with its download and upload speed right now and what it has moved since you opened this section. The processes of one program (a browser starts several) are added up in a single row.\n\nTraffic is measured with Windows' own event tracing, the same source as Resource Monitor. It only counts bytes and which program moved them, never the content, and it runs only while this section is open.\n\n“Conn.” is how many TCP connections the program has established. Programs that closed keep their totals until you leave this section.\n\nThe link icon shows that program's connections. The block icon cuts it off the network with a Windows Firewall rule you can undo in “Blocks”.
net.help.connections = Every TCP connection open on this PC: which program, the address and port at the other end, and the state. The other end is shown as an IP address, TURBiX doesn't look up names because that would send queries over the internet.\n\nNext to the address you'll see the service that port usually belongs to (HTTPS on 443, for example) and whether the other end is on this PC, on your local network or on the internet.\n\nThe X closes the connection right away (IPv4 only, the program may open another one). The block icon blocks that address in both directions. Your router and DNS servers can't be blocked, that would cut your internet.
net.help.ports = Programs that are waiting for other devices to connect (TCP) or receiving data (UDP).\n\n“Only this PC” means nothing outside can reach the port. “Open to the network” means any device that can reach this PC may try, and whether that includes the internet depends on your router.\n\nPorts that are usually worth a look when open to the network (file sharing, remote desktop, databases) are marked “REVIEW”. It doesn't mean there's a problem: ports 135 and 445 are normal in Windows. If you don't use the feature, you can block the port.\n\nThe block icon adds a Windows Firewall rule that stops incoming connections to that port. The program keeps working on this PC.
net.help.blocks = What you've blocked with TURBiX. They are normal Windows Firewall rules in the “TURBiX” group: Windows keeps enforcing them even if TURBiX is closed or uninstalled, and you can also see them in “Windows Defender Firewall with Advanced Security”.\n\n“Unblock” deletes the rule and the program or address can use the network again. TURBiX never touches rules it didn't create.
