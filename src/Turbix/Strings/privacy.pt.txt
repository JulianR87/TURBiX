# ---------------------------------------------------------------- aba
privacy.title = Privacidade e telemetria
privacy.subtitle = Escolha quais dados o Windows deixa de enviar. Antes de mudar qualquer coisa, o TURBiX salva um backup para você poder desfazer.
privacy.preset.help = Recomendado: ajustes seguros para qualquer PC, sem efeitos colaterais visíveis.\n\nMáximo: inclui também os ajustes AVANÇADOS, que bloqueiam mais dados mas podem desativar algum recurso (digitação por voz, localização, Copilot…). Leia os avisos em amarelo antes de aplicá-los.
privacy.restorePoint = Criar ponto de restauração antes de aplicar
privacy.restorePoint.help = Cria um ponto de restauração do Windows antes de aplicar as alterações. É uma segunda rede de segurança, além do backup que o TURBiX sempre salva. A Proteção do Sistema precisa estar ativada; se não estiver, o TURBiX avisa e continua.

# ---------------------------------------------------------------- Telemetria
privacy.tweak.diagnosticData.name = Dados de diagnóstico no mínimo
privacy.tweak.diagnosticData.summary = Reduz ao mínimo o que o Windows envia para a Microsoft.
privacy.tweak.diagnosticData.help = Define por política o nível mais baixo de dados de diagnóstico, oculta o nome do dispositivo nos relatórios e limita o envio de logs e despejos de memória.\n\nNo Windows Home e Pro, o mínimo permitido é “Obrigatórios”: por isso este ajuste vem junto com a desativação do serviço e das tarefas de telemetria.

privacy.tweak.telemetryServices.name = Serviço de telemetria (DiagTrack)
privacy.tweak.telemetryServices.summary = Para o serviço que envia os dados de diagnóstico.
privacy.tweak.telemetryServices.help = Desativa “Experiências de Usuário Conectado e Telemetria” (DiagTrack), o serviço que coleta e envia os dados de diagnóstico, e o serviço de roteamento de mensagens WAP Push (dmwappushservice) que o acompanha. O Windows funciona normalmente sem eles.
privacy.tweak.telemetryServices.warning = Em PCs de empresa gerenciados com Intune/MDM, o dmwappushservice pode ser necessário.

privacy.tweak.telemetryTasks.name = Tarefas agendadas de coleta
privacy.tweak.telemetryTasks.summary = Desativa 10 tarefas que coletam dados em segundo plano.
privacy.tweak.telemetryTasks.help = O Windows executa tarefas agendadas que fazem um inventário do seu PC e dos seus programas e enviam o resultado: Avaliador de Compatibilidade, Programa de Aperfeiçoamento da Experiência do Usuário (CEIP), censo do dispositivo, SQM e o coletor de dados de diagnóstico de disco. Desativá-las também economiza uso de disco e CPU em segundo plano.

privacy.tweak.ceip.name = Programa de aperfeiçoamento (CEIP) e inventário
privacy.tweak.ceip.summary = Para de inventariar e relatar os programas instalados.
privacy.tweak.ceip.help = Desativa o Programa de Aperfeiçoamento da Experiência do Usuário, o coletor de inventário de aplicativos, a telemetria de compatibilidade (AIT) e o Gravador de Passos (uma ferramenta antiga que quase ninguém usa mais).

privacy.tweak.errorReporting.name = Relatório de Erros do Windows
privacy.tweak.errorReporting.summary = Não envia para a Microsoft os relatórios de travamentos.
privacy.tweak.errorReporting.help = Quando um programa fecha inesperadamente, o Windows prepara um relatório (às vezes com parte da memória do programa) e o envia para a Microsoft. Este ajuste desativa isso. Os erros continuam sendo registrados no próprio PC, no Visualizador de Eventos.

privacy.tweak.feedback.name = Pedidos de comentários
privacy.tweak.feedback.summary = O Windows para de pedir sua opinião.
privacy.tweak.feedback.help = Remove as janelas que pedem para você avaliar o Windows e desativa as tarefas que baixam e agendam essas pesquisas.

# ---------------------------------------------------------------- Privacidade
privacy.tweak.advertisingId.name = ID de publicidade
privacy.tweak.advertisingId.summary = Os aplicativos não podem rastrear você com um ID de publicidade.
privacy.tweak.advertisingId.help = O Windows atribui a cada usuário um identificador único que os aplicativos usam para mostrar anúncios personalizados e relacionar sua atividade entre aplicativos. Este ajuste o desativa.

privacy.tweak.activityHistory.name = Histórico de atividades
privacy.tweak.activityHistory.summary = Não guarda nem envia o que você abre no PC.
privacy.tweak.activityHistory.help = O Windows registra quais aplicativos, arquivos e páginas você abre e pode sincronizar isso com sua conta Microsoft. Este ajuste impede que isso seja guardado e enviado.

privacy.tweak.tailoredExperiences.name = Experiências personalizadas
privacy.tweak.tailoredExperiences.summary = Seus dados de diagnóstico não são usados para anúncios.
privacy.tweak.tailoredExperiences.help = Impede que a Microsoft use seus dados de diagnóstico para mostrar dicas, anúncios e recomendações “personalizadas” no Windows.

privacy.tweak.inkingTyping.name = Coleta de escrita à tinta e digitação
privacy.tweak.inkingTyping.summary = Não envia amostras do que você digita.
privacy.tweak.inkingTyping.help = O Windows pode coletar o que você digita no teclado ou escreve com a caneta para “melhorar” o reconhecimento e o dicionário pessoal, e enviar relatórios de erros de escrita à mão. Este ajuste impede isso. O corretor e as sugestões do teclado continuam funcionando.

privacy.tweak.languageList.name = Lista de idiomas para sites
privacy.tweak.languageList.summary = Os sites não veem sua lista de idiomas.
privacy.tweak.languageList.help = Impede que os sites leiam a lista de idiomas configurada no Windows, um dado que também serve para identificar seu PC (impressão digital do navegador).

privacy.tweak.appDiagnostics.name = Diagnóstico de outros aplicativos
privacy.tweak.appDiagnostics.summary = Os aplicativos não podem ler dados de diagnóstico de outros.
privacy.tweak.appDiagnostics.help = Impede que os aplicativos da Microsoft Store acessem as informações de diagnóstico dos outros aplicativos instalados.

privacy.tweak.appLaunchTracking.name = Rastreamento de aplicativos abertos
privacy.tweak.appLaunchTracking.summary = O Windows para de registrar quais programas você usa.
privacy.tweak.appLaunchTracking.help = O Windows anota cada programa que você abre para organizar o menu Iniciar e a pesquisa. Este ajuste desativa esse registro.
privacy.tweak.appLaunchTracking.warning = A lista “Mais usados” do menu Iniciar ficará vazia.

privacy.tweak.onlineSpeech.name = Reconhecimento de fala online
privacy.tweak.onlineSpeech.summary = Sua voz não é enviada para os servidores da Microsoft.
privacy.tweak.onlineSpeech.help = O reconhecimento de fala online envia sua voz para a nuvem da Microsoft para transcrevê-la. Este ajuste o desativa e também bloqueia a personalização de entrada.
privacy.tweak.onlineSpeech.warning = A digitação por voz (Win + H) vai parar de funcionar.

privacy.tweak.location.name = Serviço de localização
privacy.tweak.location.summary = Nenhum aplicativo consegue saber sua localização.
privacy.tweak.location.help = Desativa completamente a localização do sistema para o Windows e todos os aplicativos.
privacy.tweak.location.warning = Param de funcionar o Mapas, o clima automático, “Localizar meu dispositivo” e o fuso horário automático.

# ---------------------------------------------------------------- Anúncios
privacy.tweak.webSearch.name = Pesquisa na Web e Bing no menu Iniciar
privacy.tweak.webSearch.summary = O que você pesquisa no Windows não é enviado ao Bing.
privacy.tweak.webSearch.help = Por padrão, cada letra que você digita na pesquisa do Windows é enviada ao Bing para mostrar resultados da Web. Com este ajuste a pesquisa fica só no PC (seus aplicativos, arquivos e configurações), mais rápida e privada. Também desativa a Cortana.

privacy.tweak.suggestionsAds.name = Anúncios e instalação automática de aplicativos
privacy.tweak.suggestionsAds.summary = Sem sugestões, publicidade nem aplicativos promovidos.
privacy.tweak.suggestionsAds.help = Remove as “sugestões” do menu Iniciar e das Configurações, as dicas e anúncios da tela de bloqueio, a publicidade do OneDrive no Explorador de Arquivos e as telas de “Aproveite ainda mais o Windows”, e impede que o Windows instale por conta própria aplicativos promovidos.
