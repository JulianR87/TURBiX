# ---------------------------------------------------------------- Memory
memory.tab = Memory (RAM)
memory.usage.title = Memory usage
memory.usage.help = How much RAM Windows and your programs are using right now. Above 85–90%, Windows starts using the disk as memory and everything slows down, games most of all.
memory.available = {0} available
memory.clean.button = Free up memory
memory.clean.help = Frees up RAM now without closing any programs:\n\n1. Asks every program to give back memory it has reserved but isn't using.\n2. Empties “standby” memory (cache of files that are already closed), which Windows is sometimes slow to release and can cause stutter in games.\n\nNothing is lost: programs load whatever they need again on their own. That's why usage goes back up over time, and why a program may take a moment longer when you switch back to it. It helps right before you start a game or when memory is almost full, it won't speed up a PC that has plenty of RAM to spare.

gaming.gameMode.name = Game Mode on
gaming.gameMode.summary = Windows gives the game priority and holds off its heavy tasks.
gaming.gameMode.help = With Game Mode, Windows gives the game processor and graphics priority, and avoids installing drivers or showing Windows Update restart notifications while you play. It's usually on already, this makes sure it is.

gaming.gameDvr.name = Background recording (Game DVR)
gaming.gameDvr.summary = Stops recording your game nonstop “just in case.”
gaming.gameDvr.help = Windows can keep recording the last few seconds of your game all the time so you can save a clip. That recording keeps the graphics card and disk busy, and it's a known cause of FPS drops and stutter, especially on modest PCs. This setting turns it off.
gaming.gameDvr.warning = You won't be able to record clips or screenshots with Xbox Game Bar (Win+Alt+G). Recorders from NVIDIA, AMD, OBS or Steam aren't affected.

gaming.gameBarPopups.name = Xbox Game Bar pop-ups
gaming.gameBarPopups.summary = Removes the pop-up tips and stops it opening with the controller button.
gaming.gameBarPopups.help = Stops Xbox Game Bar from showing tips when you start a game and from popping up over your game when you press the Xbox button on the controller. Game Bar stays installed and still opens with Win+G.

gaming.stickyKeys.name = Keyboard accessibility shortcuts
gaming.stickyKeys.summary = Pressing Shift 5 times no longer kicks you out of the game.
gaming.stickyKeys.help = Turns off the shortcuts that open Sticky Keys (Shift five times), Filter Keys (hold right Shift for 8 seconds) and Toggle Keys (Num Lock for 5 seconds). In games they go off by accident and minimize the game. The features themselves are still available in Settings › Accessibility.
gaming.stickyKeys.warning = If you use Sticky Keys, Filter Keys or Toggle Keys, don't apply this setting. Takes effect when you sign out.

gaming.mouseAccel.name = Mouse acceleration
gaming.mouseAccel.summary = The pointer always moves the same distance, whether you move fast or slow.
gaming.mouseAccel.help = Turns off “Enhance pointer precision.” With that option on, the faster you move the mouse the farther the pointer goes, which makes aiming by muscle memory hard in shooters. Without it, movement is 1:1 and predictable.
gaming.mouseAccel.warning = The mouse will also feel different on the desktop. Takes effect when you sign out or restart.

gaming.mmcss.name = Multimedia priority for games
gaming.mmcss.summary = Reserves less processor time for background tasks while you play.
gaming.mmcss.help = By default, Windows reserves 20% of the processor for background tasks while multimedia is playing. This setting lowers that to 10% and raises the processor, graphics and disk priority of the “Games” profile. The gain is small, but it helps keep FPS steady on processors with few cores.

gaming.hags.name = Hardware-accelerated GPU scheduling
gaming.hags.summary = The graphics card manages its own memory (lower latency).
gaming.hags.help = Turns on Hardware-accelerated GPU scheduling (HAGS). It lowers processor load and latency on modern cards, and it's required for DLSS 3 and FSR 3 frame generation. Needs Windows 10 version 2004 or later and an NVIDIA GTX 1000 / AMD RX 5000 card or newer with up-to-date drivers.
gaming.hags.warning = Requires a restart. On older cards or with old drivers it can cause stutter, if that happens, revert the setting.

gaming.powerPlan.name = “High performance” power plan
gaming.powerPlan.summary = The processor doesn't slow down to save power.
gaming.powerPlan.help = Turns on the Windows “High performance” plan. The processor stays at a high clock speed and doesn't “park” cores, which avoids micro-stutter when a game suddenly needs more power. If your PC doesn't have that plan (common on many modern laptops), the setting shows as “Doesn't apply.”
gaming.powerPlan.warning = Uses more electricity and runs hotter. On laptops it shortens battery life, so use it plugged in.

gaming.powerThrottling.name = Power throttling for programs
gaming.powerThrottling.summary = Windows stops slowing down background programs to save battery.
gaming.powerThrottling.help = Windows slows down programs it considers “in the background” to save power. Sometimes that also slows down launchers, voice chat or recorders while you play. This setting turns that throttling off.
gaming.powerThrottling.warning = Uses more battery on laptops.

gaming.edgeBackground.name = Microsoft Edge in the background
gaming.edgeBackground.summary = Edge no longer stays in memory after you close it.
gaming.edgeBackground.help = Turns off Edge's Startup boost (which preloads it when the PC starts) and stops its extensions from running after you close it. Frees memory and processes even if Edge isn't your browser.
gaming.edgeBackground.warning = Edge will show “Managed by your organization” in its settings, that's normal when policies are used.

gaming.backgroundApps.name = Store apps in the background
gaming.backgroundApps.summary = Microsoft Store apps don't do any work while they're closed.
gaming.backgroundApps.help = Stops Microsoft Store apps (Mail, Photos, Weather and so on) from running in the background to update themselves or send notifications. Frees up processor and memory, especially on Windows 10.
gaming.backgroundApps.warning = Store apps won't notify you about new things (new mail, messages) while they're closed.

gaming.widgets.name = Widgets and “News and interests”
gaming.widgets.summary = Removes the news panel from the taskbar, along with its processes.
gaming.widgets.help = Turns off Widgets on Windows 11 and “News and interests” on Windows 10. That panel keeps several browser processes open all the time to show weather and news.
gaming.widgets.warning = The widgets/weather button disappears from the taskbar.

gaming.visualEffects.name = Transparency and animations
gaming.visualEffects.summary = Removes visual effects that use the graphics card on the desktop.
gaming.visualEffects.help = Turns off transparency effects and window and taskbar animations. You'll notice it most on PCs with integrated graphics or little memory: the desktop responds faster and more of the graphics card is left for the game.
gaming.visualEffects.warning = Windows will look flatter and without animations. Some of it takes effect when you sign out.

# Abrir TURBiX al iniciar Windows
startup.self.title = Open TURBiX when Windows starts
startup.self.detail = It waits next to the clock, so the automatic memory cleanup keeps working without you having to remember.
startup.self.help = TURBiX opens by itself every time you sign in to Windows. If the icon next to the clock is on (Settings), it waits there without opening the window, otherwise it opens minimized to the taskbar. It's mainly so the automatic memory cleanup is always on.\n\nWhen it opens it doesn't apply settings or clean anything on its own: it only does what you've turned on.\n\nBecause TURBiX needs administrator rights, Windows won't open it from the usual startup list. So a task called “TURBiX” is created in Task Scheduler, which opens it without asking you to confirm. Turning the option off deletes the task.\n\nIf you move TURBiX to another folder, turn it on again.
