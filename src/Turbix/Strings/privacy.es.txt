# ---------------------------------------------------------------- Telemetría
privacy.tweak.diagnosticData.name = Datos de diagnóstico al mínimo
privacy.tweak.diagnosticData.summary = Reduce al mínimo lo que Windows envía a Microsoft.
privacy.tweak.diagnosticData.help = Configura por directiva el nivel más bajo de datos de diagnóstico, oculta el nombre del equipo en los informes y limita el envío de registros y volcados de memoria.\n\nEn Windows Home y Pro el mínimo permitido es «Obligatorio»: por eso este ajuste se combina con desactivar el servicio y las tareas de telemetría.

privacy.tweak.telemetryServices.name = Servicio de telemetría (DiagTrack)
privacy.tweak.telemetryServices.summary = Detiene el servicio que envía los datos de diagnóstico.
privacy.tweak.telemetryServices.help = Desactiva «Experiencias del usuario y telemetría asociadas» (DiagTrack), el servicio que recopila y sube los datos de diagnóstico, y el servicio de mensajes WAP Push (dmwappushservice) que lo acompaña. Windows funciona con normalidad sin ellos.
privacy.tweak.telemetryServices.warning = En equipos de empresa administrados con Intune/MDM, dmwappushservice puede ser necesario.

privacy.tweak.telemetryTasks.name = Tareas programadas de recopilación
privacy.tweak.telemetryTasks.summary = Desactiva 10 tareas que recopilan datos en segundo plano.
privacy.tweak.telemetryTasks.help = Windows ejecuta tareas programadas que inventarían tu equipo y tus programas y envían el resultado: Evaluador de compatibilidad, Programa de mejora de la experiencia (CEIP), censo del dispositivo, SQM y el recopilador de diagnóstico de disco. Desactivarlas también ahorra uso de disco y CPU en segundo plano.

privacy.tweak.ceip.name = Programa de mejora (CEIP) e inventario
privacy.tweak.ceip.summary = Deja de inventariar y reportar tus programas instalados.
privacy.tweak.ceip.help = Desactiva el Programa para la mejora de la experiencia del cliente, el recopilador de inventario de aplicaciones, la telemetría de compatibilidad (AIT) y la Grabación de acciones de usuario (una herramienta antigua que ya casi nadie usa).

privacy.tweak.errorReporting.name = Informe de errores de Windows
privacy.tweak.errorReporting.summary = No envía a Microsoft los informes de bloqueos.
privacy.tweak.errorReporting.help = Cuando un programa se cierra inesperadamente, Windows prepara un informe (a veces con parte de la memoria del programa) y lo envía a Microsoft. Este ajuste lo desactiva. Los errores se siguen registrando localmente en el Visor de eventos.

privacy.tweak.feedback.name = Solicitudes de comentarios
privacy.tweak.feedback.summary = Windows deja de pedirte tu opinión.
privacy.tweak.feedback.help = Elimina las ventanas emergentes que piden valorar Windows y desactiva las tareas que descargan y programan esas encuestas.
