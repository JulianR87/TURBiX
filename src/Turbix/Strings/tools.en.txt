# ------------------------------------------------------------------ Windows Registry
regfix.note = TURBiX looks for registry entries that point to programs or files that no longer exist: broken startup items, “ghost” programs in the uninstall list and leftovers from deleted programs. Removing them stops error messages, but it won't make your PC any faster; no registry cleaner does. Only entries that can be verified are flagged, and everything is backed up before it's deleted.
regfix.scan = Find problems
regfix.help = What gets checked:\n\n• Broken startup: programs Windows tries to open at startup that no longer exist.\n• Ghost program: listed as installed, but its files and uninstaller are gone.\n• App path and Shared DLL: references to deleted files.\n• Name cache: names of programs that are no longer there.\n\nWhat is NOT touched: COM classes, file associations, services or anything that can't be verified. Nor anything on removable or network drives, since they may simply be disconnected.
regfix.footer = Each entry is backed up before it's deleted. You can get it back from Restore.

regfix.cat.startup = Broken startup
regfix.cat.uninstall = Ghost program
regfix.cat.appPath = App path
regfix.cat.sharedDll = Shared DLL
regfix.cat.muiCache = Name cache

regfix.detail.missing = Missing: {0}
regfix.detail.missingFolder = Folder missing: {0}
regfix.help.startup = Windows tries to open this program every time you sign in, but the file no longer exists (usually because it was uninstalled). It can cause an error message at startup.
regfix.help.uninstall = It shows up in the list of installed programs, but its files and uninstaller no longer exist. That's why it can't be uninstalled from Windows and stays in the list as a “ghost”.
regfix.help.appPath = Windows uses this entry to find the program when you type its name in Run. The program is gone, so the entry is useless.
regfix.help.sharedDll = A counter for a file shared by several programs. The file no longer exists, so the counter isn't needed.
regfix.help.muiCache = Windows remembers the name of every program that was ever opened, even if it was later deleted or was just a downloaded installer. It's only a cache: removing these entries doesn't affect anything, and neither does leaving them.
