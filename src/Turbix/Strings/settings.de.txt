settings.tray.text = Doppelklick öffnet TURBiX; per Rechtsklick können Sie Speicher freigeben, temporäre Dateien bereinigen oder beenden.
settings.tray.help = Solange TURBiX geöffnet ist, erscheint sein Symbol im Infobereich neben der Uhr der Taskleiste. Wenn Sie es nicht sehen, steckt es vielleicht unter dem Pfeil „Ausgeblendete Symbole einblenden“; von dort können Sie es in die Taskleiste ziehen.\n\nDoppelklick öffnet das Fenster. Per Rechtsklick: Arbeitsspeicher freigeben, temporäre Dateien bereinigen, Einstellungen öffnen oder TURBiX beenden.\n\nWenn Sie die Option ausschalten, erscheint das Symbol nur kurz, wenn TURBiX eine Benachrichtigung anzeigt.

settings.closeToTray.title = Beim Schließen des Fensters weiterlaufen
settings.closeToTray.text = Das X blendet das Fenster aus und TURBiX bleibt neben der Uhr. Zum vollständigen Schließen wählen Sie „TURBiX beenden“ im Menü des Symbols.
settings.closeToTray.needsIcon = Dafür ist das Symbol neben der Uhr nötig: Ohne es käme man nicht zum Fenster zurück, daher beendet das X TURBiX.
settings.closeToTray.help = Mit dieser Option beendet das X TURBiX nicht: Es läuft neben der Uhr weiter, und die automatische Freigabe von Arbeitsspeicher geht weiter. Um zurückzukehren, doppelklicken Sie auf das Symbol oder öffnen TURBiX erneut.\n\nZum vollständigen Schließen klicken Sie mit der rechten Maustaste auf das Symbol und wählen „TURBiX beenden“.\n\nOhne diese Option beendet das X TURBiX wie jedes andere Programm.\n\nBei ausgeblendetem Fenster nutzt TURBiX den Prozessor kaum: Es prüft nur alle 30 Sekunden den Arbeitsspeicher.
settings.confirmExit.title = Vor dem Beenden nachfragen
settings.confirmExit.text = Fragt vor dem Beenden von TURBiX nach, damit Sie es nicht versehentlich schließen.
settings.confirmExit.help = Zeigt eine Rückfrage, bevor TURBiX vollständig beendet wird, ob über „TURBiX beenden“ im Menü des Symbols oder mit dem X, wenn Sie es so eingestellt haben.\n\nLäuft gerade eine Aufgabe, wird TURBiX nie mittendrin beendet: Es wartet, bis sie fertig ist, ob diese Option an ist oder nicht.
