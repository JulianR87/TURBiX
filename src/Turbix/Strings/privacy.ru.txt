privacy.restorePoint.help = Перед применением изменений создаётся точка восстановления Windows. Это вторая страховка в дополнение к резервной копии, которую TURBiX сохраняет всегда. Для этого должна быть включена защита системы, если она выключена, TURBiX предупредит об этом и продолжит работу.

# ---------------------------------------------------------------- Телеметрия
privacy.tweak.diagnosticData.name = Минимум диагностических данных
privacy.tweak.diagnosticData.summary = Сводит к минимуму то, что Windows отправляет в Microsoft.
privacy.tweak.diagnosticData.help = Через политику задаёт самый низкий уровень диагностических данных, скрывает имя устройства в отчётах и ограничивает отправку журналов и дампов памяти.\n\nВ Windows «Домашняя» и Pro минимально допустимый уровень — «Обязательные», поэтому эта настройка дополняется отключением службы и задач телеметрии.

privacy.tweak.telemetryServices.name = Служба телеметрии (DiagTrack)
privacy.tweak.telemetryServices.summary = Останавливает службу, которая отправляет диагностические данные.
privacy.tweak.telemetryServices.help = Отключает службу «Функциональные возможности для подключенных пользователей и телеметрия» (DiagTrack), которая собирает и отправляет диагностические данные, и сопутствующую ей службу маршрутизации push-сообщений WAP (dmwappushservice). Windows без них работает как обычно.
privacy.tweak.telemetryServices.warning = На рабочих компьютерах, которыми управляют через Intune/MDM, служба dmwappushservice может быть нужна.

privacy.tweak.telemetryTasks.name = Запланированные задачи сбора данных
privacy.tweak.telemetryTasks.summary = Отключает 10 задач, которые собирают данные в фоне.
privacy.tweak.telemetryTasks.help = Windows запускает задачи по расписанию, которые составляют опись компьютера и программ и отправляют результат: оценщик совместимости, программа улучшения качества программного обеспечения (CEIP), перепись устройства, SQM и сборщик диагностических данных диска. Если их отключить, заодно снизится фоновая нагрузка на диск и процессор.

privacy.tweak.ceip.name = Программа улучшения качества (CEIP) и инвентаризация
privacy.tweak.ceip.summary = Больше не собирает и не отправляет список установленных программ.
privacy.tweak.ceip.help = Отключает программу улучшения качества программного обеспечения, сборщик инвентаризации приложений, телеметрию совместимости (AIT) и средство записи действий (старый инструмент, которым почти никто не пользуется).

privacy.tweak.errorReporting.name = Отчёты об ошибках Windows
privacy.tweak.errorReporting.summary = Не отправляет в Microsoft отчёты о сбоях.
privacy.tweak.errorReporting.help = Когда программа неожиданно закрывается, Windows готовит отчёт (иногда с частью памяти программы) и отправляет его в Microsoft. Эта настройка отключает отправку. Ошибки по-прежнему записываются на компьютере, их можно посмотреть в «Просмотре событий».

privacy.tweak.feedback.name = Запросы отзывов
privacy.tweak.feedback.summary = Windows больше не спрашивает ваше мнение.
privacy.tweak.feedback.help = Убирает всплывающие окна с просьбой оценить Windows и отключает задачи, которые загружают и планируют эти опросы.
