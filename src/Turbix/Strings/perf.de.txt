startup.self.title = TURBiX beim Windows-Start öffnen
startup.self.detail = Es wartet neben der Uhr, damit die automatische Freigabe von Arbeitsspeicher läuft, ohne dass Sie daran denken müssen.
startup.self.help = TURBiX öffnet sich bei jeder Windows-Anmeldung von selbst. Ist das Symbol neben der Uhr eingeschaltet (Einstellungen), wartet es dort, ohne das Fenster zu öffnen; sonst startet es minimiert in der Taskleiste. Das ist vor allem dafür da, dass die automatische Freigabe von Arbeitsspeicher immer aktiv ist.\n\nBeim Start wendet es keine Einstellungen an und bereinigt nichts von sich aus: Es tut nur, was Sie eingeschaltet haben.\n\nWeil TURBiX Administratorrechte braucht, lässt Windows es nicht über die normale Autostart-Liste starten. Deshalb wird in der Aufgabenplanung eine Aufgabe namens „TURBiX“ angelegt, die es ohne Rückfrage öffnet. Wenn Sie die Option ausschalten, wird die Aufgabe gelöscht.\n\nWenn Sie TURBiX in einen anderen Ordner verschieben, schalten Sie sie erneut ein.
startup.self.taskDescription = Öffnet TURBiX bei der Anmeldung. Wird in TURBiX angelegt und gelöscht (Einstellungen).
